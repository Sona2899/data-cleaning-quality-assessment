# 📊 Data Cleaning & Quality Assessment Case Study

### 🧠 Overview
Validated 40,000+ operational transaction records by identifying missing and inconsistent data using SQL, Python, and Excel. Implemented business-driven reporting inclusion logic to ensure data reliability without deleting records, delivering analysis-ready datasets for downstream KPI reporting and business decision-making.

### 🎯 Business Objective
- Ensure data quality before analytics and reporting  
- Identify and quantify missing or inconsistent data  
- Apply business rules for reporting inclusion and exclusion  
- Deliver reliable, analysis-ready datasets  

### 🗂️ Data
- Operational transactions dataset  
- 40,000+ records  
- Includes transaction details, customer information, order dates, and payment attributes  

### 🛠️ Tools Used
- 🧩 **SQL** – Data profiling, missing value analysis, quality checks  
- 🐍 **Python (Pandas)** – Data cleaning, validation, and transformation  
- 📈 **Microsoft Excel** – Reporting inclusion logic, reconciliation, validation  

### 🔍 What I Did (Step-by-Step)
- Performed data profiling using SQL to identify missing and inconsistent values  
- Cleaned and validated transaction data using Python (Pandas)  
- Implemented Excel-based reporting inclusion logic to flag incomplete records without deleting data  
- Conducted pivot-based reconciliation to validate record counts and reporting readiness  
- Prepared final, analysis-ready datasets for KPI reporting  

### 📌 Key Quality Checks
- Missing order date identification  
- Reporting inclusion vs exclusion flagging  
- Record count reconciliation  
- Data consistency validation across tools  

### 💡 Key Outcomes
- Validated 40,000+ operational records  
- Reduced data quality issues by approximately 35%  
- Ensured reliable datasets for KPI reporting and business decision-making  
- Preserved all raw data while applying business-safe reporting logic
